## C. 影集分組

`/媒體資料庫/HBO/來！金來號 ！/01/來！金來號 ！01.mp4` 這種結構，
五集變成**五個獨立的「電影」條目**。

**原因與 TMDB 無關**：檔名結尾的 `01` 沒被認出是集數（緊貼標題、沒有 `EP`／`第01集`／`S01E01` 標記），
上層資料夾 `01` 也沒被認出是季別。集數留在標題裡 → 每集算出不同的合併鍵。
是**先被拆開才導致 TMDB 查不到**，不是反過來。

### 新增規則

| # | 規則 | 條件 |
|---|---|---|
| 1 | 所在資料夾是純數字或 `EP01`／`E01`／`第01集` → 那是集數，劇名取上一層 | 需 **≥2 個同型態兄弟資料夾** |
| 2 | 檔名尾端 1–3 位數字當集數 | 需**同群組內多個檔案共用相同標題前綴、尾數不同**。單檔不套用 |
| 3 | 規則 1 或 2 成立 → `kind` 強制為 `tv` | |

**結構性調整**：`parse()` 現在逐檔判斷，不知道兄弟檔案與兄弟資料夾長什麼樣。
規則 1、2 都需要群組資訊，所以 `walk()` 要把同層的兄弟名稱一起傳進解析器。

### 重新分組

> **目前的完整掃描不會重新解析檔名。** `_index_file` 開頭就是
> 「檔案大小沒變就只更新 `seen_at` 然後 return」。

- 新增 `POST /api/scan?full=true&reparse=true` 強制重新解析。
- 後台放「重新分組」按鈕，說明「會重新解析所有檔名，不會重新下載中繼資料」。
- 重新分組後清孤兒條目。

**影響**：條目 id 會變。播放進度綁 `file_id` 所以**會保留**；手動指定過的 TMDB 配對要重做。

### 驗收

- `來！金來號 ！` 五個檔案合併成一部影集五集。
- **既有正確分組的 6 部影集（7～33 檔）分組不變** ← 最重要的回歸測試。
- 單檔電影不會被誤判成影集。

## D. 相片庫排除影片封面

679 張裡混進 4 張影集封面（`2024 人生複本 Dark Matter S01.jpg` 等，
所在目錄都是 8～9 個影片配 1 張圖）。

### 排除規則（符合任一）

1. 檔名（去副檔名）**與所在資料夾同名**
2. 常見封面名：`poster`／`fanart`／`cover`／`folder`／`thumb`／`banner`／`backdrop`／`landscape`／`disc`
3. 與**同目錄某個影片檔同主檔名**

規則 1、3 只在「同目錄有影片」時套用。新增開關 `PHOTO_EXCLUDE_VIDEO_ARTWORK=true`（預設開）。

**已在真實資料上驗證：兩種判斷各自都剛好抓到那 4 張，零誤傷**；
Shasin 底下影片與相片真的混在一起的資料夾一張都沒被排除。

重新掃描時，已存在但現在符合排除規則的要一併刪除，並在日誌顯示「排除了 N 張影片封面」。

## E. 換頁捲動

現在換頁執行 `window.scrollTo({top: 0})` — 捲到**整份文件頂端**，
在標頭、搜尋列、資料夾標籤之上，離格線還有一大段。影片海報牆同一段程式碼。

- 捲動目標改成格線容器頂端減去標頭實際高度（動態量，不寫死）。
- **已經在目標位置上方就不捲** — 在頂端按下一頁不該有任何跳動。
- 相片與影片共用同一個函式。
- 尊重 `prefers-reduced-motion`。

## F. iPhone 全螢幕

`pl.requestFullscreen?.()` 中 `pl` 是 `<div>`，而 **iOS Safari 上 `div.requestFullscreen` 不存在**，
`?.` 讓它安靜地什麼都不做。也沒有 `webkitRequestFullscreen` 備援。

### 三種模式

| 模式 | 做法 | 保留 | 失去 |
|---|---|---|---|
| **自動**（預設） | 桌機／Android 用 Fullscreen API；iPhone 用網頁全螢幕 | 各平台最好的結果 | — |
| **網頁全螢幕** | CSS `position:fixed` 撐滿、`100dvh`、鎖背景捲動 | **自訂控制列、自繪字幕全保留** | Safari 網址列可能還在 |
| **原生全螢幕** | `video.webkitEnterFullscreen()` | 畫面乾淨、系統手勢 | 自訂控制列與**自繪字幕的外觀設定** |

### 原生全螢幕下的字幕

不必在「原生全螢幕」與「有字幕」之間二選一。已解析好的 cue 可以同時餵給原生字幕軌：

```js
const t = video.addTextTrack('subtitles', label, lang);
t.mode = 'disabled';                        // 平常關著，自繪那層在工作
t.addCue(new VTTCue(start, end, text));     // 邊解析邊加，沿用現有漸進式載入
```

進入原生全螢幕時切成 `showing` 並隱藏自繪圖層，退出時反過來。
**漸進式字幕載入（大檔第一句 0.11 秒）的優勢完全保留。**

### 其他

- 補 `webkitRequestFullscreen` 備援。
- 監聽 `webkitendfullscreen`，使用者從系統播放器退出時還原狀態。
- 版面高度改 `100dvh`。
- 橫向鎖定：能用的平台才呼叫；**iOS Safari 不支援，不要假裝有**，也不要因它失敗就中止全螢幕。

**需要在實體 iPhone 上實測** — 開發環境沒有 iOS，模擬器重現不了 `webkitEnterFullscreen` 的真實行為。
